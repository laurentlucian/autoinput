# AutoInput

Free, open-source mouse and keyboard automation for Windows. Auto-click, hold, key repeat, key hold, global hotkeys (F6/F7/F8), multiple saved setups.

[Download](https://github.com/laurentlucian/autoinput/releases)

## Develop

Needs [Rust](https://rustup.rs/), [Bun](https://bun.sh/), and [Tauri v2 prerequisites](https://v2.tauri.app/start/prerequisites/).

```sh
bun install
bun run tauri dev    # run
bun run tauri build  # build
```
